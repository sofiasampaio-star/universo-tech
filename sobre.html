Sobre o Universo Tech

Aprender tecnologia
começa com boas perguntas.

O Universo Tech é um website educativo criado para apresentar conceitos tecnológicos de forma acessível, com foco em aprendizado, responsabilidade digital e boas práticas na web.

A proposta

Por que este site foi criado?

A tecnologia está presente em atividades cotidianas, como estudar, conversar, trabalhar, comprar e acessar serviços. Mesmo assim, muitos conceitos que sustentam o mundo digital podem parecer complexos para quem está começando. O Universo Tech foi pensado para aproximar esses assuntos do público por meio de explicações organizadas e exemplos práticos.

O objetivo principal é apresentar fundamentos de desenvolvimento web, inteligência artificial e segurança digital, incentivando o visitante a continuar pesquisando e a utilizar recursos tecnológicos de maneira crítica. O conteúdo prioriza uma linguagem direta, sem deixar de explicar a importância de cada conceito.

Este projeto também representa uma aplicação prática de conhecimentos de front-end. A organização das páginas utiliza HTML semântico; a identidade visual é construída com CSS; e componentes do Bootstrap apoiam a navegação e a apresentação de conteúdos interativos, como o menu responsivo e as perguntas frequentes.

A estrutura foi dividida em três páginas para facilitar a navegação: a página inicial apresenta o propósito e os destaques; a página de tecnologias desenvolve os assuntos principais; e esta página descreve os objetivos, os princípios e as escolhas de desenvolvimento.

O site é estático, ou seja, não utiliza banco de dados nem processamento em servidor para apresentar seus conteúdos. Essa abordagem é adequada a um projeto introdutório porque permite concentrar os esforços na estrutura, no visual, na navegação e na adaptação a diferentes telas.

O resultado esperado é uma experiência clara e consistente, que funcione tanto em computadores quanto em tablets e smartphones. A proposta poderá ser ampliada futuramente com novos artigos, recursos de pesquisa ou outras áreas de conteúdo, mantendo os princípios de acessibilidade e organização.

◎

Missão

Compartilhar conhecimentos tecnológicos de maneira simples, responsável e útil para estudantes e pessoas curiosas sobre o universo digital.

◇

Princípios

Clareza, acessibilidade, respeito à privacidade, organização visual e incentivo à verificação crítica das informações.

⌘

Tecnologias utilizadas

HTML5, CSS3 e Bootstrap 5.3. O JavaScript utilizado pelo Bootstrap permite o funcionamento do menu móvel e do componente de perguntas frequentes.

Como foi construído

Decisões de desenvolvimento

O projeto considera critérios técnicos e de experiência do usuário para que a interface seja útil em diferentes situações.

▤

Estrutura semântica

Elementos como cabeçalho, navegação, conteúdo principal, seções e rodapé organizam a página de maneira lógica, melhorando a manutenção e a compreensão do documento.

◫

Design responsivo

O sistema de grade do Bootstrap e as regras de CSS permitem que os cartões, os textos e o menu se reorganizem conforme a largura disponível, incluindo telas pequenas.

✓

Acessibilidade e testes

Contraste, foco visível, textos alternativos quando imagens são usadas, rótulos claros e links descritivos ajudam diferentes pessoas a navegar e compreender o conteúdo.
